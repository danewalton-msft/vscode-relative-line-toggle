# Toggle Line Numbers

Switch VS Code line numbers between absolute and relative.

## Use

1. Open the Command Palette with `Ctrl+Shift+P` on Windows or Linux, or `Cmd+Shift+P` on macOS.
2. Search for **Toggle Line Numbers**.
3. Press Enter.

You can also select the line-number button in the editor title bar.

The extension updates the global `editor.lineNumbers` setting, so the selected mode applies to every editor window.

## Install the VSIX

1. Open the Extensions view in VS Code.
2. Select the `...` menu.
3. Select **Install from VSIX...**.
4. Choose `toggle-line-numbers-1.0.0.vsix`.
